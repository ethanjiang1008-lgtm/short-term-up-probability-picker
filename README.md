# Short-Term Up Probability Picker

一个与 `seven-factor-stock-picker` 独立的 A 股短线研究项目。

## 目标

核心目标不是预测“明天涨停”或“连板”，而是回答：

> **今天尾盘看到这只股票，明天收盘上涨的概率有多高？**

第一阶段只使用可解释的量价、尾盘和市场环境特征，先得到稳定的 `score`；历史样本足够后，再把 `score` 校准成经验概率。

主标签：`next_day_close > today_close`

辅助标签：`next_day_return >= +3%`、次日涨停。

## 交易流程

`尾盘候选 → 晚间消息/公告人工确认 → 次日竞价确认 → 决策`

系统允许“不交易”。评估同时关注胜率、平均盈利、平均亏损和期望收益。

## 数据来源

第一版沿用现有 `seven-factor-stock-picker` 已验证的数据获取思路：新浪公开行情 API、A 股日 K 线，以及超时、重试和并发抓取。模型层和数据层分离。

## 当前模型

保持小而简单，当前只保留 5 个部分：

- 个股基础强度 25%
- 尾盘强度 25%
- 板块强度 20%（第一版暂留接口）
- 事件强度 20%（第一版暂留接口）
- 市场环境 10%

当前市场环境只从涨跌幅榜估计，不再引入额外复杂数据源。

评分规则不是概率。只有历史样本达到最低数量后，校准模块才输出经验上涨率。

## 自动运行

GitHub Actions 每个工作日北京时间约 15:25 运行一次历史快照任务，把当日候选保存到 `data/history/`。独立的 `daily-scan.yml` 只保留手动运行，避免两个定时任务重复抓取。

## 研究原则

1. 预测时点不可见的信息不能进入特征。
2. 回测按日期滚动，禁止随机打乱。
3. 概率必须由历史样本校准，不能把人工 score 直接叫概率。
4. 事件必须带时间；盘后消息进入晚间流程，不回填尾盘信号。
5. 涨停、连板只是收益分布的高收益尾部，不是主目标。
6. 先保证数据和回测稳定，再加功能；不追求自动“自我学习”。

## 当前状态

v0.2：稳定的最小可用版本，包含新浪数据层、量价/尾盘特征、简单市场环境、次日标签、每日历史快照、经验校准基础和回测框架。

下一阶段只做一件重要的事：积累真实历史样本，并用 walk-forward 回测验证 `score` 是否真的对应更高的次日上涨率，再决定是否增加板块或事件能力。
