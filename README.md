# Short-Term Up Probability Picker

一个与 `seven-factor-stock-picker` 独立的 A 股短线研究项目。

## 目标

核心目标不是预测“明天涨停”或“连板”，而是回答：

> **今天尾盘看到这只股票，明天收盘上涨的概率有多高？**

第一阶段使用可解释的量价、尾盘、题材/板块与市场环境特征，输出一个候选分数；随着历史样本积累，再用严格的时间切分回测对分数做概率校准。

主标签：`next_day_close > today_close`

辅助标签：
- 次日收益 `>= +3%`
- 次日涨停

## 交易流程

`尾盘候选生成 → 晚间公告/新闻事件扫描 → 次日竞价确认 → 决策`

系统允许“不交易”。最终评估不只看胜率，还要看平均盈利、平均亏损、期望收益、最大回撤与连续亏损。

## 数据来源

第一版复用现有项目验证过的数据获取思路：新浪公开行情 API、A 股 K 线、行业/概念板块数据，并保留请求重试、超时和并发抓取能力。数据适配层与模型层分离，后续可增加其他 provider。

## 重要研究原则

1. 所有特征必须只使用预测时点之前已经可见的信息。
2. 回测必须按日期滚动切分，禁止随机打乱造成未来数据泄漏。
3. 早期输出的 `probability` 仅在有历史校准数据后才允许解释为概率；当前版本的默认输出是 `score` 与候选等级。
4. 新闻/公告事件必须带有事件时间，晚于尾盘决策时间的事件只能进入夜间流程，不能回填到当日特征。
5. 不把涨停、连板当成主目标；它们只是收益分布中的高收益尾部结果。
